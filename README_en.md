# Tensor-Sim
Bottom-up field simulation (no particles) – experimental runtime for Tensor der Realitäten

Requirements:
- Python 3.8+

Run:
```
python tensor_sim_v117.py
```

## 🔗 Connection to the Main Project

This repository is directly connected to the main project
**"Tensor der Realitäten"**:

👉 [https://github.com/RaikoPulvermacher/Tensor-Realit-ten](https://github.com/RaikoPulvermacher/Tensor-Realit-ten)

There you will find:

* the conceptual foundation
* structural diagrams
* philosophical-physical description
* the bottom-up derivation

This repository (**Tensor-Sim**) is the
**experimental runtime implementation** of these ideas
and serves as a field simulation without a particle model.
